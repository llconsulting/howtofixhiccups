Privacy

howtofixhiccups.com is a static website. There are no accounts, no comment forms, and no membership.

The Start button and countdown run in your browser. That sequence is not sent to us.

The host that serves the files may keep ordinary server logs such as IP address, browser type, and the page requested. We do not use those logs to build a profile of you.

Ad slots on the site are empty placeholders. There is no live ad network script today. If ads are added later, this page will say so, and those vendors may set cookies or collect device data under their own policies.

We do not sell personal information. We do not ask children for data. This page is not medical advice and does not collect health information.
